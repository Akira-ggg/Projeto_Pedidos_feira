# Projeto Pedidos Feira

Sistema de controle de pedidos desenvolvido em Java.

## Tecnologias utilizadas

- Java 17
- Maven
- SQLite
- JDBC

## Objetivo

Projeto desenvolvido para praticar programação Java, orientação a objetos, operações CRUD e integração com banco de dados SQLite.

## Funcionalidades

- [ ] Cadastrar pedidos
- [ ] Listar pedidos
- [ ] Atualizar pedidos
- [ ] Excluir pedidos
